🍰 Cardápio Digital - Doceria Charme

Aplicação web responsiva desenvolvida para gerenciamento de pedidos e exibição de catálogo de uma doceria. O projeto possui interface interativa com controle de estoque por item, carrinho de compras via modal e fluxo de checkout completo.

🚀 Funcionalidades

* **Catálogo Interativo:** Exibição dos produtos com imagens, descrições, preços e limite de estoque por item.
* **Controle de Quantidade:** Botões seletores para adicionar ou remover itens do pedido em tempo real.
* **Carrinho de Compras:** Visualização centralizada dos produtos selecionados com atualizações dinâmicas em janela modal.
* **Checkout e Pagamento:** Formulário para digitação do nome do cliente, escolha do método de pagamento (Pix, Cartões ou Dinheiro) e confirmação do pedido.

🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização e customização visual)
* **Bootstrap 5** (Framework para responsividade e modais)
* **JavaScript** (Lógica de negócios, manipulação do DOM e carrinho)

📂 Estrutura de Arquivos

```text
doceria-charme/
├── node_modules/          # Dependências do projeto (Bootstrap)
├── src/
│   ├── css/
│   │   └── styles.css     # Estilos e temas personalizados
│   ├── img/               # Imagens dos produtos do cardápio
│   └── js/
│       └── script.js      # Lógica do carrinho, estoque e formulário
├── index.html             # Interface e estrutura principal da aplicação
└── package.json           # Gerenciador de dependências Node.js

```

🔧 Como Executar o Projeto

Pré-requisitos: Node.js instalado (caso utilize dependências locais via NPM) e um navegador web atualizado.

1. Baixe os arquivos do projeto e certifique-se de manter a estrutura de pastas indicada.
2. No terminal, na raiz do projeto, instale as dependências executando:
```bash
npm install bootstrap

```


3. Abra o arquivo `index.html` diretamente em seu navegador ou utilize a extensão **Live Server** no VS Code para executá-lo num servidor local.
